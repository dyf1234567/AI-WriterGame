# 双界录 · 都市心动互动小说

AI 主持的都市恋爱互动游戏：你是一名获得神秘"心动系统"的大学生，从京华大学入学开始，在华夏的京都与魔都两座城市里邂逅各色女性角色，学业、事业与多条感情线并行发展。世界里的 NPC 拥有记忆与关系网，即使你不在线，世界也在自行演化。

## 运行方法

### 1. 安装依赖（首次）

```bash
cd /path/to/AI-WriterGame        # 进入项目目录（Windows 例：cd "D:\Program Files (x86)\AI WriterGame"）
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

Mac/Linux 用户：`python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt`，
启动命令把 `.venv/Scripts/python` 换成 `.venv/bin/python`（存档锁与数据目录已做双平台适配）。

### 2. 配置模型 API

复制 `.env.example` 为 `.env`，填入你的国内 OpenAI 兼容服务信息，例如（以 DeepSeek 为例）：

```
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxx
LLM_MODEL=deepseek-chat
```

智谱等兼容服务同理，把 `LLM_BASE_URL` 换成对应端点（如 `https://open.bigmodel.cn/api/paas/v4`），`LLM_MODEL` 换成对应模型名。

**不配置也能启动**：游戏会进入"演示模式"，使用内置示例剧情跑通全部流程，界面顶部会明确提示。

### 3. 启动

```bash
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000> 即可游玩。

## 玩法速览

- **三栏分格界面**：左栏地图＋系统（状态/签到/任务/背包），中栏阅读式剧情流，右栏关系网＋收件箱
- **风格切换**（顶栏色点，点击即换）：深夜 / 墨纸（两套夜间模式）、羊皮卷、青岚，选择会被记住
- **地图系统**（左栏顶）：世界 → 国家 → 城市三级 SVG 地图（华夏：京都、魔都两城共 14 地，涵盖校园/商圈/交通/自然/文化/休闲/秘境）；已探明地点正常显示，未探明区域压黑成迷雾，自由探索解锁。**点击地图打开大图**：世界层点国家、国家层点城市、城市层点建筑看详情卡（描述/常在此地之人），顶部面包屑随时回跳上级，确认后前往
- **系统界面**（顶栏"▤ 系统"）：状态（等级/属性/**穿搭栏四槽位**/签到）、背包（使用/装备/卖出）、**商城**（48 件商品：修炼/属性/约会/情趣/穿搭/特殊，含抽奖券、六条天赋路线的专项修炼道具与 12 件情趣商品——由氛围仪式感渐进到直白成人向，后者需好感「亲近」以上才可送出）、抽奖、任务、图鉴页签
- **剧情**：点选项或自由输入行动，AI 实时续写都市恋爱轻喜剧；右栏 NPC 卡片可点击查看详情（人设/记忆/关系）；剧情中新登场的人物会自动登入名册，成为日后可再相遇的活人；收件箱收离线事件与 NPC 留言——离开越久，世界变化越大
- **身份**：主角的社会身份（如「京华大学·大二学生」「街舞社副社长」）随剧情落档，显示在左栏状态面板，并作为事实喂回给 AI
- **收支**：剧情里的花费与所得如实入账，面板写明「所得：系统金币 +2／支出：系统金币 -2（请她喝奶茶）」；余额或材料不足时拒绝整个回合，既不扣款也不发货。单回合所得设护栏（金币 30 / 在售物品 1 件 / 其他 3 种，`config.py` 可调），签到与支线奖励走内部通道不受限
- **开局礼包**：系统赠送 10 次抽奖（背包使用「系统抽奖券」，四档品质 70/24/5/1，新手奖池、结果入账并记录）；初始天赋待表达培养意向（学业/运动/音乐/创业/厨艺/摄影）后按路线发放 S 级天赋，**每人限领一次**（`player.technique` 记账，重复申报会被拒绝并在面板写明，品质固定 S 级、模型改不了）；天赋显示在左栏状态面板。「系统抽奖券」属**系统专属物品**（`models.SYSTEM_ITEMS`），剧情契约不得发放或扣除，只能由系统在开局发放、抽奖时扣除
- **等级主干 10 级**：初露锋芒→校园新星→…→人生赢家；等级靠学业、事业、魅力与真心积累，进度满 100% 才能提升（一回合最多一级）
- **灵能觉醒（隐秘修行线）**：商城·特殊购入「觉醒·灵种」服下即开启——心动系统的隐藏功能，全世界只有主角知晓。境界五阶（灵觉初醒/淬体/他心通/灵犀/御气）各有实际神通：体魄永久增长、听见人物心声、短信灵犀加成、赶路不耗时段；修为靠修行丹药与剧情奇遇积累，每境满 100 突破。世界仍是普通都市，修炼必须瞒着所有人
- **主线＝等级主干**：任务面板的「人生赢家」目标与阶段由等级算出，**只有真实提升才换档**，模型写不动它；`quest_progress` 只记"近况"（最多 3 条，面板与提示词均展示）。「系统的来历」仅作可选悬念，不是必做主线
- **人物阵容**（均为成年人）：苏晚晴（青梅竹马·音乐学姐）、陈芮（发小死党）、林慧（辅导员）、顾清言（学生会长·校花）、叶泠（田径队学妹）、宋语棠（千金大小姐）、许沁（邻家插画师姐姐）、沈曼（江湾女总裁）、白靖（神秘留学生）；感情描写走心动暧昧与吃醋名场面，含蓄健康，最终与谁走到一起由玩家选择决定

## 测试

```bash
.venv/Scripts/python tests/state_growth_test.py          # 离线单元测试，不需要服务与模型 API
.venv/Scripts/python tests/regression_test.py            # 规则边界、生成失败、备份恢复、并发提交（隔离临时目录）
node tests/frontend_regression_test.cjs                 # 页面目录、抽奖入口、炼丹刷新与阅读状态回归
.venv/Scripts/python tests/smoke_test.py                 # 接口冒烟测试，需先启动服务
SMOKE_BASE=http://127.0.0.1:8001 .venv/Scripts/python tests/smoke_test.py   # 指定其他实例
```

2026-10-18 修复说明：新游戏先生成验证，再备份替换；每次存档前保留状态和归档的恢复点，最近50份可从“恢复存档”选择。旧剧情可从“往事回看”阅读。手机以剧情为默认面板，通过“地图与状态 / 人物与消息”切换。未见面人物与后台秘密不提前公开。余额不足的剧情交易会拒绝整回合，未满100%进度不能升级。

冒烟测试的第一步是 `POST /api/new`，会**覆盖** `data/state.json`；而所有实例默认共用同一个 `data/`，所以并行起第二个服务同样会冲掉正式存档。跑测试前用 `SJL_DATA_DIR` 把数据目录（存档、归档、记忆手册）整体改道：

```bash
# 隔离 + 强制演示模式（清空三个模型变量即不烧 API），再打冒烟
SJL_DATA_DIR=/d/tmp/sjl-smoke LLM_BASE_URL= LLM_API_KEY= LLM_MODEL= \
  .venv/Scripts/python -m uvicorn app.main:app --port 8001
SMOKE_BASE=http://127.0.0.1:8001 .venv/Scripts/python tests/smoke_test.py
```

## 目录结构

```

static/         前端（阅读式界面＋多风格主题，原生 HTML/CSS/JS）
```
