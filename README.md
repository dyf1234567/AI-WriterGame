# 双界录 · 都市修仙双穿互动小说

AI 主持的互动游戏：你是一名获得神秘系统的高中生，可穿梭于现代都市与修仙界两个世界。世界里的 NPC 拥有记忆与关系网，即使你不在线，世界也在自行演化。

详细设计见 [docs/DESIGN.md](docs/DESIGN.md)。

## 运行方法

### 1. 安装依赖（首次）

```bash
cd "D:\Program Files (x86)\AI WriterGame"
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

### 2. 配置模型 API

复制 `.env.example` 为 `.env`，填入你的国内 OpenAI 兼容服务信息，例如（以 DeepSeek 为例）：

```
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxx
LLM_MODEL=deepseek-chat
```

智谱等兼容服务同理，把 `LLM_BASE_URL` 换成对应端点（如 `https://open.bigmodel.cn/api/paas/v4`），`LLM_MODEL` 换成对应模型名。

**不配置也能启动**：游戏会进入"演示模式"，使用内置示例剧情跑通全部流程，界面顶部会明确提示。

### 3. 启动

```bash
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000> 即可游玩。

## 玩法速览

- **三栏分格界面**：左栏地图＋系统（修行/签到/任务/背包），中栏阅读式剧情流，右栏关系网＋收件箱
- **风格切换**（顶栏色点，点击即换）：深夜 / 墨纸（两套夜间模式）、羊皮卷、青岚，选择会被记住
- **地图系统**（左栏顶）：可视化地图——都市侧暂用虚构地名的世界地图占位，修仙侧为宗门山野图；已探明地点正常显示，未探明区域压黑成迷雾，自由探索解锁。**点击地图打开大图查看界面**：点地点看详情卡（描述/所在世界），确认后前往或穿越前往
- **系统界面**（顶栏"▤ 系统"）：状态（境界/属性/**装备栏四槽位**/签到）、背包（使用/装备/卖出）、**商城**（23 件商品）、**炼丹**（材料合成丹药）、任务（进行中/已完成状态）五个页签
- **剧情**：点选项或自由输入行动，AI 实时续写；右栏 NPC 卡片可点击查看详情（人设/记忆/关系）；剧情中新登场的人物会自动登入名册，成为日后可再相遇的活人；收件箱收离线事件与 NPC 留言——离开越久（修仙界按现实 1 小时＝ 1 天加速），世界变化越大
- **身份**：主角在两界的社会身份（如「临江三中·高三学生」「青玄宗·外门弟子」）随剧情落档，显示在左栏修行面板，并作为事实喂回给 AI
- **收支**：剧情里的花费与所得如实入账，面板写明「所得：坊市舆图 +1／支出：下品灵石 -2（向摊主买下坊市舆图）」；余额或材料不足时拒绝整个回合，既不扣款也不发货。单回合所得设护栏（灵石 30 / 在售物品 1 件 / 其他 3 种，`config.py` 可调），签到与支线奖励走内部通道不受限
- **穿越**：顶栏按钮随时穿梭两界
- **开局礼包（设定集 V1.2）**：系统赠送 10 次抽奖（背包使用「系统抽奖券」，四档品质 70/24/5/1，新手奖池、结果入账并记录）；初始功法待表达修炼意向（剑/体/法/魔/丹/阵符修）后按路线发放上品功法，**每人限领一次**（`player.technique` 记账，重复申报会被拒绝并在面板写明，品质固定上品、模型改不了）；功法显示在左栏修行面板。「系统抽奖券」属**系统专属物品**（`models.SYSTEM_ITEMS`），剧情契约不得发放或扣除，只能由系统在开局发放、抽奖时扣除
- **白手起家**：首穿落点为玄灵界青禾州荒野「落星荒野」，无宗门无人脉，靠探索接触世界（最近聚居地白溪镇）；境界主干 10 级（含炼虚/合体/大乘）
- **主线＝境界主干**：任务面板的「渡劫飞升」目标与阶段由境界算出，**只有真实突破才换档**（一回合最多一级），模型写不动它；`quest_progress` 只记"近况"（最多 3 条，面板与提示词均展示）。「两界之谜」仅作可选悬念，不再是必做主线

## 测试

```bash
.venv/Scripts/python tests/state_growth_test.py          # 离线单元测试，不需要服务与模型 API
.venv/Scripts/python tests/regression_test.py            # 规则边界、生成失败、备份恢复、并发提交（隔离临时目录）
node tests/frontend_regression_test.cjs                 # 页面目录、抽奖入口、炼丹刷新与阅读状态回归
.venv/Scripts/python tests/smoke_test.py                 # 接口冒烟测试，需先启动服务
SMOKE_BASE=http://127.0.0.1:8001 .venv/Scripts/python tests/smoke_test.py   # 指定其他实例
```

2026-10-18 修复说明：新游戏先生成验证，再备份替换；每次存档前保留状态和归档的恢复点，最近50份可从“恢复存档”选择。旧剧情可从“往事回看”阅读。手机以剧情为默认面板，通过“地图与状态 / 人物与消息”切换。未见面人物与后台秘密不提前公开。余额不足的剧情交易会拒绝整回合，未满100%修为不能突破；跨界返回必须先落回原位置。

世界观尚未定案的时间、生理年龄、跨界携带与贸易边界，见 [世界观一致性审查](docs/WORLD-AUDIT-2026-10-18.md)。

冒烟测试的第一步是 `POST /api/new`，会**覆盖** `data/state.json`；而所有实例默认共用同一个 `data/`，所以并行起第二个服务同样会冲掉正式存档。跑测试前用 `SJL_DATA_DIR` 把数据目录（存档、归档、记忆手册）整体改道：

```bash
# 隔离 + 强制演示模式（清空三个模型变量即不烧 API），再打冒烟
SJL_DATA_DIR=/d/tmp/sjl-smoke LLM_BASE_URL= LLM_API_KEY= LLM_MODEL= \
  .venv/Scripts/python -m uvicorn app.main:app --port 8001
SMOKE_BASE=http://127.0.0.1:8001 .venv/Scripts/python tests/smoke_test.py
```

## 目录结构

```
app/            后端（FastAPI + 剧情引擎 + 离线演化）
static/         前端（阅读式界面＋多风格主题，原生 HTML/CSS/JS）
docs/DESIGN.md  设计定稿文档
tests/          单元测试与接口冒烟测试
data/state.json 运行时存档（自动生成）
data/story_archive.jsonl 移出状态窗口的旧剧情正文（自动追加；压缩失败也不会丢正文）
```
