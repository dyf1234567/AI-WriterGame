# 规则决策表（P1-04）

依据 [RULES.md](../../docs/RULES.md)（机制层单一事实来源）。状态：**保留**＝正典已定、新引擎必须遵守；**推荐**＝本轮给出的首章参数，进入实现前可调；**待定**＝需要拍板，首章按推荐值临时执行并在实现中集中可配（`content/rules/engine_config.yaml`，阶段 3 落地）。

| 项目 | 状态 | 决策 | 说明 / 边界 |
|---|---|---|---|
| 双穿 | 保留 | 随时、免费、瞬间；落点守恒（返回某界落回离开时的位置） | 不以剧情理由临时剥夺；张力来自留下的同伴、期限与被监视的落点 |
| 时间流速 | 保留 | 现实 1h＝玄灵界 1 天；都市 1:1 | 引入**基准时钟**（见下）统一结算，不再由正文口头描述 |
| 基准时钟 | 推荐 | 库内统一存“基准秒”；世界时间＝基准秒×该界倍率。行动耗时按所在界结算后换算基准秒，同时推进两界日历 | 都市 ΔT=1，玄灵界 ΔT=24（相对现实）；穿越动作本身 0 耗时 |
| 离线 | 保留＋推荐 | 保留：45 分钟阈值、单次结算封顶 7 天（现实）。新增：超封顶时长入**待结算队列**，分批消化；离线只结算到期事件与 NPC 计划，不新增主线 | 待结算区间带游标，绝不重复结算、不静默吞时长 |
| 生理年龄 | 推荐 | 按主角**亲身经历**的基准时长累计；世界日历不自动加龄。延寿规则暂不实现（境界 4+ 再议） | 首章时间跨度小，先记账不表现 |
| 行动耗时 | 推荐 | 移动/交易/交谈/探索按节点表耗时；修炼按“段”结算（一段＝玄灵界半日）；等待/休息显式声明时长 | 模型响应等待不计入游戏时间 |
| 携带 | 推荐 | 徒手 5 格、双肩包 +10 格（开局有）；储物袋 +20（商城 100 灵石，正典已有）。**活体不可穿越**；物品穿越无申报但有目击风险（都市侧异常传播按事件卡） | 容量按“件”计，材料可叠组 |
| 通信 | 推荐 | 手机仅都市有网；传讯玉简仅玄灵界内互通；**跨界不通**，系统通知除外（系统面板两界可见） | 跨界传书只能靠亲自跑或托人 |
| 货币 | 保留 | 都市法定货币与灵石无固定汇率；青禾州通 行下品灵石（商城体系沿用） | 首章不做汇率模型，跨界交易走剧情事件定价 |
| 失败 | 推荐 | 首章**无永久死亡**。失败形态：受伤（影响行动）、损失（钱/货/脸面）、关系破裂、事件走向恶化分支 | 拒绝参与是合法选择，世界照走 |
| 战斗 | 推荐 | 仅 4 动作：威慑（魅力/境界压制）、短兵相接（体魄+装备，掷 D6）、逃跑（优先结算，落点守恒兜底）、救助。胜/平/败三种结算，均产生事件与见证 | 数值沿用四维与装备加成表 |
| 修炼效率 | 保留 | 都市低效、玄灵界高效；境界≥筑基后都市修炼收益减半（新增，推荐） | 首章玩家炼气，影响不大 |
| 突破 | 保留 | 修为满 100 才可突破；单回合/单行动最多一级 | 灵材前置暂不实现 |
| 资源有来处 | 保留 | 商铺有库存与补货周期；矿脉/灵药有储量。首章把白溪镇三家商铺做成真实库存 | 模型不得凭空造货 |
| 所得护栏 | 保留 | 剧情申报上限灵石 30/在售物品 1/其他 3 种；签到、支线、抽奖走内部通道 | 先裁决后生成后，护栏变成“候选产出上限” |
| NPC 行动 | 推荐 | 核心卡按“目标→条件→行动”的日程表由规则推进；模板 NPC（商贩、路人）不进模型 | 每回合只更新在场与到期人物 |
| 知情 | 推荐 | 见证者模型：秘密按获知事件传播（目击/转述/书信）；NPC 上下文只装它可知的内容 | 详见 `content/protocols.md` |
| 记忆 | 保留 | 事实账本/行事录/摘要/检索四层沿用；新增知识与承诺独立表（阶段 4） | 摘要可重建，不作为事实来源 |
| 都市主城 | 保留 | 青临市（运行版口径），避开“天都” | — |
