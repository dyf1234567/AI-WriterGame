# 2026-10-21 游玩体验与主线修复

## 玩家能感受到的变化

- 修复浏览器严格模式下 `photoFallback` 未声明导致整页初始化中断的问题；增加真实初始化路径的前端回归。
- 白天仍有稳定可读的正文底色；选项两列排列并可收起；中栏常驻主线入口。关系称呼与好感阶段分开显示，图鉴按真实名册计数。
- 新增五章「星河计划·第一学期」：报名方向 → 组队与三周筹备 → 承诺冲突 → 成果展演 → 关系收束与期末回顾。六个方向各有具体筹备任务，三位搭档各有个人目标；作品准备、关系投入、守约或赶稿会影响后续结果。
- 章节由关键经历推进，等级继续作为独立成长。跨周行动明确推进日期，晚些开始也不会倒拨时间。主线节点使用内置分支保障过程与收束，自由行动仍由 AI 主持；演示模式也可完成主线。
- 完成主线后，玩家主动选择合适的伴侣或独行，终章引用本局路线、成果、冲突和修复方式。好感并列不会替玩家选人；不再让大一新生因满级而毕业。旧档及旧结局保留。
- 短信重要事实和玩家明确承诺进入共同记忆；具体邀约记录确认状态，事实了结后同步对应约定。疑问、转述、假设及模型额外编造的承诺不当作玩家承诺。
- 剧情、礼物、离线与灵犀短信共享关系跨档处理；下降显示关系变化，每次只消化一条关系事件。生日奖励调整为双倍、单次最多 +15，修复生日当天周限豁免。
- 统一剧情、支线、签到与物品的升级和成就结算；零数量的所得/支出占位不入账。专项课程收益更合理，同路线额外 +20%，初始天赋提供对应属性；抽奖专属奖品有实际使用效果。
- 统一开局人物与时段；点名人物、当前搭档、任务与未兑现承诺优先进入叙事上下文。终章状态送入模型，番外沿用已经确认的关系。

## 存档兼容

本轮不重置正式存档。已有等级、物品、人物与记忆保留；没有新主线记录的旧档从报名开始，已经存在的旧结局继续保留。缺失主线前置资料时回退到可恢复的行动，不生成空人物卡关。主线和终章沿用现有事务与恢复点机制。

## 使用

通过 `start.bat` 启动的服务会自动重载后端，浏览器刷新即可加载新界面。手动启动且没有启用自动重载的服务，需要重新启动。进入游戏后点击中栏「主线任务」开始或继续星河计划。
