# 《双界录》游戏内容与功能总览

> 本文基于当前代码实现整理（`app/`、`static/`、`tests/`），与设计文档 [DESIGN.md](DESIGN.md) 互为补充：DESIGN.md 记录设计决策过程，本文记录游戏实际具备的内容与功能。

## 一句话简介

AI 主持的都市修仙双穿互动小说：你是一名获得神秘系统的高中生，可随时穿梭于现代都市与修仙界两个世界。NPC 拥有记忆与关系网，即使你不在线，世界也在自行演化。

---

## 1. 世界观设定

- **都市侧（urban）**：现代国家"夏澜"，主角是青临市临江三中的高三学生。世界表象是寻常现代生活，暗地里存在超凡暗流——隐世修行者、异常事件、对"另一个世界"略有知觉的机构。班主任林慧是隐藏修行者伏笔。
- **修仙侧（xianxia）**："玄灵界"，九州加东溟海域（分层正典：青禾州已细化，其余为远方传闻）。灵石是硬通货，境界即地位。**主角白手起家**：首穿落点为荒野「落星荒野」，无宗门无人脉，一切靠探索（最近聚居地：白溪镇）。
- **系统原则**：来历不解释，不设必须破解的系统身世主线；「两界之谜」只是可选长线悬念。开局礼包：**系统抽奖券×10**（背包使用）＋**初始功法领取资格**（表达修炼意向后按路线发放上品功法：剑/体/法/魔/丹/阵符）。
- **穿越规则**：随时可在两界间穿梭（瞬间完成）；重大剧情节点可临时锁定，但须给出剧情理由。
- **时间流速**：都市侧与现实 1:1；修仙界加速——现实 1 小时＝修仙界 1 天。
- **两界对彼此皆是隐秘**：都市侧几乎无人知晓修仙界存在。

## 2. 核心玩法循环

1. **剧情推进**：AI 实时生成 150~350 字网文笔法的剧情段落，每段给 3~4 个方向不同的选项，同时提供自由输入框——玩家可以做任何合理行动（去任何地点、找任何人、打听、交易、修炼、惹事、逃避……），世界必须给予有内容的回应。
2. **自由度原则**（写入提示词）：
   - 世界不围着玩家转：NPC 有自己的日程、动机与关系，每回合的 `npc_events` 体现世界自主呼吸；
   - 未明说的场景元素（小店、摊贩、路人、杂役）按世界观自行补全；
   - 适度主动制造偶遇与意外，但重大转折要有因果铺垫；
   - 探索有奖：探索可揭示地图迷雾地点或登记全新地点；
   - 修炼按环境灵气给收益（都市侧效率低、修仙侧高，演示模式中体现为 +300% 效率提示）。
3. **关系是活的**：双层关系网——玩家↔NPC 好感度（0~100），NPC↔NPC 自主发展恩怨情仇；好感度数值显隐可由顶栏开关控制。
4. **离线演化**：不玩的时候世界也在走，回来时按离开的真实时长结算（详见第 7 节）。

## 3. 主角与成长系统

### 3.1 境界体系

`凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升`（境界主干 10 级，另含凡人占位）

- 开局觉醒即踏入**炼气**（realm=1），修为进度 5%；
- 修为进度满 100% 自动突破，或由剧情 `realm_breakthrough` 触发；
- 提示词约束：单回合修为增幅通常不超过 10。

### 3.2 属性（四维）

`体魄 / 神识 / 悟性 / 魅力`，初始 5 / 6 / 8 / 6。属性丹可永久 +1（上限 99），装备提供附加成；面板显示"基础+加成"（如 `体魄 5+2`）。

### 3.3 装备栏（四槽位）

`武器 / 防具 / 法宝 / 足履`。可装备物品与加成：

| 装备 | 槽位 | 加成 | 商城价 |
|---|---|---|---|
| 玄铁短剑 | 武器 | 体魄+2 | 120 |
| 青霜剑 | 武器 | 体魄+4 | 400 |
| 护心镜 | 防具 | 体魄+3 | 180 |
| 避水珠 | 法宝 | 神识+3 | 200 |
| 踏云靴 | 足履 | 体魄+1、魅力+1 | 160 |

同槽自动换装（旧装备退回背包）；穿上离开背包、卸下退回背包。

### 3.4 任务系统

- **主线**：「渡劫飞升」＝境界主干派生。`main_quest` 的标题/阶段/目标全部由 `player.realm` 算出（`QUEST_MILESTONES` 与 `REALMS` 等长），**只有真实突破才换档，一回合最多升一级**；模型的 `quest_progress` 改不动目标与阶段，只能追加"近况"（上限 3 条，面板与提示词都展示）。「两界之谜」不再占用主线字段，仅作可选长线悬念（主持规则4 禁止为推主线硬塞身世戏）。
- **支线**：自由探索触发（模型契约 `new_side_quest`）；带"进行中 / 已完成"状态；完成时由模型 `quest_complete` 匹配任务名，自动结算奖励——**灵石×15＋修为+8**，并发系统通知。

### 3.5 每日签到

每天一次（按自然日判定），从 7 项奖池随机：
下品灵石×10、下品灵石×15、《青禾引气诀·残页》×1（收藏品，无机制效果）、聚气丹×1、千年灵芝×1、系统灌顶修为+8、洗髓灵液修为+5。修为奖励满 100% 时同样触发突破。

## 5. 地图系统（可视化 SVG 地图）

- **规模**：都市 10 地、修仙 12 地，各有类型标签（城市/城镇/宗门/荒野/秘境/海域）与两句话描述。
- **已探明地点**正常显示地名标记；**未探明地点**压黑成迷雾（黑雾＋"？"），不可点击，通过探索/剧情揭示。
- **交互流程**：点击左栏小地图 → 打开**大图查看界面**（可两界切换）→ 点击地点标记弹出**详情卡**（名称/描述/所在世界/类型/是否当前所在/常在此地之人）→ 确认后"前往此地"或"穿越并前往"（异界地点）。同界探索有"🔎 在此探索"按钮。
- **标记细节**：当前位置脉冲高亮（◈）；地点带百分比坐标；剧情新登记的地点无坐标时按名称散列自动落位；单界地点数上限 24。
- **引擎契约**：`location`（剧情落脚点变化）与 `new_places`（新地点登记/揭示既有迷雾），由剧情 AI 在场景转移与探索时输出。

## 7. 离线演化（"世界在你不在时也在走"）

本地程序无云端常驻，实际做法是**下次打开游戏时按离开的真实时长结算**：

- 触发阈值：离开超过 **45 分钟**；结算封顶 **7 天**（防止烧穿 token）；
- 时间折算：都市侧按 1:1 折算天数；修仙侧按现实 1 小时＝1 天折算（上限 365 天）；
- 由 AI 批量生成"你不在时发生了什么"：事件流（3~6 条）＋ NPC 留言（0~3 条）＋ 好感变化 ＋ NPC 间关系事件，写入**收件箱**（保留最近 50 条）并结算关系变化；
- 规则约束：NPC 按人设自然行动；不许替玩家做重大决定、不让主角蒙受不可逆损失，但可留下麻烦、契机与钩子；
- 离线结算失败不阻塞继续游戏。

## 8. 界面与交互

**三栏分格布局 ＋ 阅读式剧情流 ＋ 玻璃拟态视觉。**

- **顶栏**：游戏名 / 演示模式徽标 / 当前世界与位置 / 穿越按钮 / 风格色点一键切换 / 好感度显隐开关 / 系统按钮 / 新游戏。
- **左栏**：地图（两界切换、迷雾、当前位置）、修行面板（境界/修为进度/属性）、每日签到、任务（主线+支线）、背包。
- **中栏**：阅读式剧情流（衬线排版、"第 N 幕"分节、打字机效果——仅当读者位于底部才跟随滚动），选项按钮组＋快捷动作（修炼 / 探索此地 / 查看四周）＋自由输入框。
- **右栏**：关系网（NPC 卡片，点击弹出详情：人设/好感/常在地/近期记忆/人物关系）、收件箱（离线事件与 NPC 留言，新消息有红点）。
- **弹窗**：地图大图、系统界面、NPC 详情、新游戏。
- **系统界面**（顶栏"▤ 系统"）五个页签：**状态**（境界/修为/属性/装备栏四槽位/签到）、**背包**（网格物品格，使用/装备/卖出）、**商城**、**炼丹**、**任务**。

## 9. AI 引擎与提示词契约

剧情引擎每回合向模型提交：世界观设定＋当前状态快照（世界/境界/属性/装备/背包/任务/地图/关系网）＋滚动剧情摘要＋最近 10 段剧情＋玩家行动；要求模型**只输出一个 JSON 对象**：

```json
{
  "story_text": "本段剧情正文，150~350字",
  "narration_world": "urban | xianxia",
  "choices": ["选项一", "选项二", "选项三"],
  "state_updates": {
    "realm_progress_delta": 0,          // 修为增减
    "realm_breakthrough": false,        // 强制突破
    "item_gained": [],                  // 获得物品
    "affinity_changes": [],             // 好感变化（含原因，写入NPC记忆）
    "new_side_quest": null,             // 新支线
    "quest_progress": null,             // 本阶段做过什么（只进近况，不推阶段）
    "quest_complete": null,             // 本回合完成的支线标题（自动发奖励）
    "npc_events": [],                   // NPC间事件（落入双方关系与记忆）
    "location": null,                   // 本段落脚点（优先已探明地点）
    "new_places": []                    // 登记/揭示地点
  },
  "system_notice": "系统面板通知文本"
}
```

- **记忆工程**：长期事实账本（承诺/伏笔/秘密，回合申报＋压缩萃取）＋归档关键词检索（行动提到谁就捞回谁的相关旧剧情）＋冲突裁决（账本为准）。详见 docs/RULES.md。人可读的 `data/memory/记忆手册.md` 随每次存档自动导出。
- **剧情压缩**：日志超过 30 段时，旧段落由模型压缩成 ≤300 字滚动摘要（保留关键因果、关系变化、伏笔、成长节点），保留最近 12 段；日志硬上限 60 段。
- **容错**：模型调用失败重试 2 次；JSON 解析容忍代码围栏与前后杂文；选项不足 2 个时给保底选项。
- **好感约束**：单回合变化通常在 -10~+10，大幅变化仅限重大情节。

### 模型接入与演示模式

- 模型：国内 OpenAI 兼容接口，`.env` 配置 `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL`（DeepSeek、智谱等均可）；
- 三项齐全才启用真实模型，否则进入**演示模式**：内置示例剧情（开局系统觉醒、穿越落星荒野、白溪镇遇黑袍人、天台之约等段落＋修炼/探索/离线结算的演示分支），可跑通全部流程，界面顶部明确提示"演示模式"；
- 旧存档自动迁移：补齐新增 NPC、新增地点、装备栏、位置等字段。
