# 都市人生 · 系统终端界面设计

## 本轮方向

用户反馈上一版像简单表单，地图缺少地理感，颜色切换藏得太深，GM 后台与主界面不一致，并明确要求都市或系统感。本轮采用夜蓝系统终端：城市天际线、细网格背景、连接状态、青色模块边线和金色行动入口；地图使用分层地理绘制，阅读与人物消息保持独立的信息层级。

- 顶部：品牌、四种具名配色、世界地图、人生手册、GM 后台和阅读设置。配色按钮在手机也始终可见，不依赖隐藏菜单。
- 桌面上下文栏：当前游戏日期、位置与安排行程、职业事业、寻找下一站入口。
- 左侧：可展开的城市地图放在第一屏，随后是今日行程、华夏币与系统积分两个独立钱包、成长与人生目标。
- 中央：章节封面与城市线稿、阅读工具、活动栏、正文、行动底座。活动选项横向浏览，正文获得更稳定的高度。
- 右侧：人物自主生活、熟人关系、手机与收件箱；不同层级使用不同边界，避免所有内容都成为相同卡片。

## 颜色与字体

夜蓝以 #0b1625 为底、阅读页 #122236、面板 #14263a、系统青 #7cc8ec、行动金 #e3c58c；墨纸采用灰黑与银色，书页采用纸白与棕墨，青岚采用深绿与米白。正文使用本机中文宋体，标题、导航与数值使用本机无衬线字体，不联网取字体。主界面和 GM 共用主题名称与存储；GM 四主题正文、次要文字和主按钮对比度均超过 4.5:1。

主界面样式以 `.travel-workspace` 为范围，新的布局块负责顶部、分栏、阅读、地图容器和响应式行为。地图内的地理绘制由 `atlas.css` 独立负责。主题通过语义颜色变量呈现，保留焦点环和减少动画设置。

## 地图容器

桌面地图占主要区域，地点清单在地图下方独立滚动，旅行详情在右侧。手机保留可见地图；地图、当前详情、地点清单按顺序排列。切换范围会清除旧详情，选点会显示真实路费和耗时。新容器在 `.atlas-directory` 中收纳结果计数与清单，原有元素 ID 和接口保持一致。

地图本身使用海岸、地形、河流、街区、道路、航线、地图符号与坐标层次表达地理关系，避免用一组相同大卡片替代地图。城市图与世界图共享点选语义，缩放和拖动不影响地点选择。

`static/atlas.js` 与 `atlas.css` 独立承担地图绘制：6国具有不同海岸与岛链，国家图显示交通网络，城市图显示建筑、绿地、桥梁和分类地标。地点标签避让，当前所在与选中目的地之间显示路线。提供缩放、方向平移、复位和指针拖动；不劫持滚轮。世界范围的国家筛选显示“全部国家”，城市列表包含所有城市，切到具体城市后同步所属国家。

## GM 控制中心

`static/gm.html`、`gm.css`、`gm.js` 重整为玩家与资源、商城与抽奖、角色档案三个分区。桌面保留侧边导航和存档概览，手机改为顶部导航。资源调整提供预览；商城草稿在保存失败后保留；人物搜索、出场筛选与逐人编辑草稿可用。保存角色时的空格清洗不会重新产生未保存草稿。双币请求、存档版本冲突和原有接口继续生效。

## 共享主题

`static/theme.js` 提供 `window.CityTheme.apply(key)`、`current()`、`themes` 和 `names`。主题键为 `night`、`ink`、`parchment`、`qinglan`。按钮可以使用 `data-theme-choice="night"`，也兼容 `data-theme="night"` 与原有 `.theme-dot`。

选择会写入 `sjl-theme`，同步 `body[data-theme]`、按钮 `aria-pressed` 和当前样式。浏览器的 `storage` 事件使主界面与 GM 后台立即跟随另一页的配色选择；原有 `applyTheme` 改变 body 属性时由观察器兼容。存储不可用时仍能切换当页配色。

## 验证与取舍

本地设计检索返回了面向营销页的通用 Hero 与按钮方案，和本游戏不符，未套用其版式或字体。随后针对活动状态的查询支持可见选中态和可中断状态切换；其他取舍来自本项目的城市生活主题与技能的通用可访问性规则。

五套前端回归（原有、沙盒、地图、GM、主题）与四份脚本语法检查全部通过。地图覆盖6国16城118地点、全部城市标签避让、SVG引用隔离与转义、裁剪层内的路线、缩放/平移/复位及拖动。完整隔离 HTTP 冒烟77项、GM页面与实际引用资源5项全部通过。

实际浏览器检查了1440×1000、670×900、390×844：主界面与GM无页面横向溢出，四种具名主题可见，世界和街区地图保留可见高度，旅行按钮可到达，主界面与GM跨页同步四主题。手机行动选项改为横向浏览，保留完整自由输入框并增加正文空间。浏览器发现的裁剪层路线插入错误已经修复，复测选点生成两层路线且无控制台错误。缩放和方向平移经真实界面操作验证，拖动经控制器回归验证。
