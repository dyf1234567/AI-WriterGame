# 产品一页纸（P1-01）

一句话：AI 主持的都市修仙双穿互动小说——你做什么，世界就因此发生可理解的变化；人物记得，并据此改变选择。

## 核心体验（按优先级）

1. **因果可见**：关键行动改变真实资源、人物立场或事件状态，且后续能被看见（谁做的、为什么、导致了什么）。
2. **人物自主**：NPC 有自己的目标、期限与底线；好感高不等于服从，拒绝也讲得出理由。
3. **两界联动**：在一边花时间，另一边照常走（24 倍流速）；都市的约与修仙的事互相挤压。
4. **自由但有边界**：任何合理行动都会被认真裁决；做不到的事得到可解释的拒绝，而不是假成功。

## 首章范围（第一章「白溪断药」）

- 空间：白溪镇及周边（落星荒野、青石村、黑风岭、灵溪山、青禾坊市）＋都市侧青临市（家、临江三中）。
- 人物：8 张核心卡（都市：周母、林慧；修仙：玄阳子、洛清衣、莫老；白溪镇：温掌柜、阿岩娘、邬三爷）。既有人物优先深化，不为了凑数换人。
- 主冲突：白溪镇药材供应中断（详见 `content/chapters/chapter_01/events.md`）。
- 篇幅：约 30—50 次有效行动；至少三种实质不同的收束，拒绝与失败都有后续路径。
- 保留设定（不改）：随时免费双穿、落点守恒、境界主干、开局抽奖与初始功法、不强制系统身世。

## 首章不做

完整九州模拟、多职业、自动经营、向量库、永久死亡（重伤与关系破裂可以）。战斗仅 4 个动作：威慑、短兵相接、逃跑、救助。

## 阶段结束条件

玩家不追身世、不拜宗门也能走完一章；「帮助 / 有代价交易 / 拒绝」三条路径全程可玩并导向不同世界状态；离线与读档不产生鬼魂数据。
