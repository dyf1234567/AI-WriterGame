# 人生沙盒、双币与地图更新

本轮基于 `24571d4`，覆盖策划差距复核列出的缺陷和玩法缺口，并加入用户追加的双币、地图与界面重整。

## 账户与旧档

现实经济使用**华夏币**：生活、兼职、活动报酬、公司、股权、作品、战队、旅行。系统玩法使用**系统积分**：商城、签到、抽奖与成长奖励。两账户独立，不能拿积分支付现实投资，也不能出售货币物品套取另一种余额。

新档为200华夏币、3系统积分和原有开局抽奖券。旧「系统金币」逐枚迁移为系统积分，不清空背包；未建立现实钱包的旧档一次性补200华夏币，迁移重复读取不再发放。原有资产和事业迁入持续对象；存档不因切换领域重置。

- 新发现的室内地点不会把既有世界地图裁成24个节点。读档保留国家、城市、探索和NPC实际位置。

## 时间与长期生活

游戏以分钟计时。一般交谈和短信15分钟，集中练习或课程120分钟。可以安排完整天数的训练、工作、上课、休息，一次最多1095天。短期兼职、练习另有每日次数限制；一分钟工作不能领取整天工资。

统一时钟逐日回收工资、团队成本、企业现金流、项目、人物计划、人物成长和过期活动。长期工作收入、训练经验和课程学分按已经完成的天数入账，较早的项目不能使用未来的收入或训练水平；训练预算提前预留，毕业后停止课程奖励。同一节点重复读取不再结算。现实离线时间不消耗游戏日，也不调用模型制造离线故事；恢复时仅补当前游戏日已经到期的事实。

学籍支持上课积累学分、休学、复学、退学、毕业。毕业需至少三个学年与120学分。年级、身份和人生阶段随真实教育及事业状态变化，18岁的创业者也可能先形成社会影响力。

## 事业、经营与行动

娱乐、电竞、商业分别保存职业、阶段、名望、团队与项目。一个领域一个在途项目，不同领域可以并行。可以首日创办公司、直接作为资本方收购战队；创业不必先成为歌手或职业选手。

经营对象拥有稳定ID和各自账本：公司有现金、估值、定价、需求和竞争；作品有制作、交付、发行渠道、受众和收入；战队有六人名单、五人阵容、训练、对手、比赛和战绩。融资进入企业账户，持股比例守恒，分红按实际股份计算。高阶项目的同一份奖励股权不会反复复制。委托经理可以在预算允许时续接项目。

自由输入支持前往地点、练习、长期安排、创业、入行、收购、发行和关系行动。模型可以把较复杂表达提议为结构化世界行动，但规则仍核验资金、权限、实体和玩家授权。咨询、犹豫或拒绝不等于同意交易。


## 人物、关系与故事

NPC按照附近、相关远处、背景三个精度层安排生活。计划到期后执行、留下结果，再安排下一步；同日尚未到达的时段不会提前兑现。8位核心人物（梁雅婷、郭瑞莹、邓碧瑶、雅倩、王德芙、韩冰、傲寒、炭炭）各有3阶段成长事件，可以合作、支持、竞争、放手，也会在玩家不参与时继续生活。多次互动的动态人物提升重要程度，优先保留。

六维关系之外，新增友谊、暧昧、恋人、异地、分手等长期状态。表白需信任、吸引与真实共同经历；对方先回应，玩家再确认。专一、开放、多人约定受各人的原则约束，非排他关系必须所有涉及的人接受；同意可以撤回，旧提议会过期。学期结局同样经过关系规则，不能仅凭高好感强行确立恋爱。

秘密按真实在场、直接通信与传播来源记录。回忆、未来打算、转述、被提及，以及“别让她知道”都不等于见证。普通私人事实也默认私密，只有实际公开发布才成为公共信息。

40种世界事件覆盖校园、事业、人物和日常，支持准备、不同参与角色、主持、赞助、社交、观众和忽略。每场独立记录结果，不可重复领奖；未参加的事件照常结束。导演读取真实演出、公司、发行作品、战队、目标和关系安排后续机会。

客观人生目标核验存档事实，包括公司、估值、持股、作品、技能、冠军、毕业等。不能用手动记录把不存在的十亿公司标记完成；主观目标仍允许自评记录。

星河计划成为可暂缓、可继续的校园篇章，原有筹备、冲突、展演和期末收尾保留。三份证据的可选世界暗线可以调查、核对，最后合作或旁观，也能随时搁置。超凡力量存在于都市的隐秘层并受到组织与社会规则限制。

## 界面与验收

界面采用都市系统终端：城市天际线、连接状态、网格背景、自己的行程和双钱包、宽阅读区、人物自主近况与消息。提供时间安排、三领域切换、企业操作、人物成长与关系协商入口。夜蓝、墨纸、书页、青岚四种配色始终可见，与 GM 后台跨页同步。设计说明见 [界面设计](UI-DESIGN-2026-10-22.md)。

新增回归套件覆盖事业、事件目标、人物、完整跨界存档及迁移/隐私/时钟边界；前端使用原有与新增VM交互检查。完整跨界验证从实际初始资金和正常劳动收入出发，走到作品发行、传媒公司、战队持有，再推进三个月，并检查经济、人物与事件幂等。

此前本机套接字与审批额度造成的验收阻塞已解除。使用独立存档、禁止外部模型的本机HTTP服务完成了真实浏览器验收：1440×1000桌面三栏与世界地图、390×844手机生活与地图面板、全世界搜索、余额不足禁用、十天工作、国际旅行、到达后的创作活动，以及通过表单创办公司并查看持股和账本。截图保存在 `artifacts/sandbox-fix-2026-10-22/desktop-atlas.jpg`、`desktop-company.jpg`、`mobile-life.jpg`、`mobile-map.jpg`。企业状态使用中文，账目显示具体用途与收支符号，面向玩家的成立/交付通知不暴露内部编号。正式存档与真实模型未用于测试；测试服务与临时浏览器已关闭。

回归验证：事业16项、事件与目标9组（40模板×2结果）、人物11项（8人×5方式×3阶段）、跨界整合8项、边界与端点17项、逐日结算顺序3项、玩法17项、叙事9项（288剧情路径）、成长139条与状态429条检查全部通过；原有和新增两套前端交互检查通过。最终代码的真实HTTP冒烟77项、新接口实际HTTP验收9项、接口回归16项、校园篇章14项复跑通过。另补地图切换/键盘交互、旅行费用去重、问询授权与逐日活动结算的定向回归；日志位于同一验收目录。
