# 当前功能总览

以2026-10-22人生沙盒更新为准，详细规则见[人生沙盒、双币与地图更新](SANDBOX-UPDATE-2026-10-22.md)。

| 系统 | 当前可玩能力 |
| --- | --- |
| 世界地图 | 6国16城118初始地点，海岸/地形/街区地标分层，缩放/平移/拖动、搜索筛选、地点活动、真实旅行费用与时间 |
| 双币经济 | 华夏币用于现实生活和经营；系统积分用于商城、签到和系统奖励；旧档幂等迁移 |
| 游戏时间 | 分钟计时、完整天数日程、最多三年快进、逐日补结算；现实离线冻结 |
| 学业与人生 | 上课学分、年级、休复学、退学、毕业；阶段结合身份与事业 |
| 自由事业 | 娱乐/电竞/商业多领域同时持有，不同领域项目并发，职业角色可切换 |
| 持续资产 | 公司、作品、战队、合同、股权、员工、企业现金、融资和按股分红 |
| 领域决策 | 作品发行渠道和受众、公司定价与现金流、战队阵容训练与比赛、委托经营 |
| 技能与成长 | 12技能、四属性、10级成长、穿搭加成、初始天赋和隐秘修炼 |
| 世界事件 | 40种模板，独立场次、准备、多身份、赞助、胜负与缺席结果、因果导演 |
| 人物生活 | 三级模拟精度、计划执行与下一步、独立事业和社交、8核心人物各3阶段成长 |
| 长期关系 | 六维、友谊/暧昧/恋人/异地/分手、双方确认、非排他各方协商与撤回 |
| 长期目标 | 客观目标按资产、公司、估值、股权、技能、作品、冠军、毕业等事实核验；主观目标记录 |
| 剧情篇章 | 可选星河计划完整学期收尾；可暂缓继续；三证据可选世界暗线 |
| 记忆与隐私 | 事实账本、承诺回收、长期归档、来源校验和私密知情名单、短信共同记忆 |
| 日常系统 | 商城、轮换货架、背包、装备、礼物、签到、抽奖、朋友圈与短信 |
| 存档 | 原子写入、版本冲突防护、事务回滚、恢复点、旧档迁移和人物归档重逢 |
| 主持人工具 | 性格/身份/偏好编辑，系统积分与华夏币独立发放、道具与成长管理 |
| 界面 | 都市系统终端、双钱包、宽阅读页、行程规划、人物近况、四主题与移动端；GM资源/商城/角色分区和共享配色 |

全部人物均为成年人；游戏内互动遵循角色原则与明确同意。世界和人物的状态更新以存档事实为准，模型叙述不能自行生成资金、股权、作品发行或关系结果。

## 验证入口

- `tests/sandbox_career_test.py`：多事业、项目与实体经济。
- `tests/sandbox_events_goals_test.py`：40模板分支、事件实例、现金与客观目标。
- `tests/sandbox_people_test.py`：8人多路径成长、自主计划、关系和可选暗线。
- `tests/sandbox_integration_test.py`：从正常初始资金走完整跨界生活链。
- `tests/sandbox_boundary_test.py`：双币迁移、隐私来源、分钟边界与无套接字端点流程。
- `tests/sandbox_frontend_test.cjs`：地图、双钱包、事业、人物、时间与响应式基础。

现有成长、叙事、玩法、前端、接口与存档回归继续保留。所有写入测试都应使用隔离目录；浏览器实测的环境限制见更新说明。
