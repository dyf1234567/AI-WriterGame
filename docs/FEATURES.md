# 当前功能总览

以 2026-10-23 为准。粒度到"系统有什么能力"，具体规则见代码与[任务台账](TASK-LEDGER.md)。

## 核心玩法

- AI 主持人回合制剧情：自由文本行动，模型按契约输出正文与结构化状态，引擎结算一切数值
- 演示模式：无模型环境下可完整游玩（脚本剧情＋确定性结算）
- 行动路由：自由输入自动识别为 旅行/生活/时间/关系/事业/活动/主线 等结构化指令，规则核验后生效
- 询问守卫：问价、盘算、带未核验条件的表达只讨论不结算，面板明示

## 心动系统（随身系统）

- 状态面板：等级、属性、技能、事业、背包、任务、地图一屏可查
- 每日签到与收件箱（事件/留言/朋友圈动态）
- 系统商城：常驻目录＋每日随机货架＋系统特供道具（成长/双倍时段/属性强化/技能灌顶/抽奖保底）
- 老虎机抽奖：四档品质权重、幸运保底道具、抽取历史
- 初始天赋（六路线一次领取）、成就系统
- 隐藏修炼线：灵能觉醒、六境进阶（隐秘设定，不公开于世）

## 角色与关系（35 人名册）

- 好感度 0-100 六档阶段（初识→羁绊）；满 100「羁绊」百依百顺、有求必应
- 关系状态机：朋友/恋人/异地/分手/复合；确立恋爱＝好感≥85 一步达成；专一/开放/多模式直接选择
- 角色卡（chara_card_v2 全员）：声口、例句、关系语气，随 GM 档案自动同步
- NPC 自主生活：目标、近况、心情、日程与下一步；8 位核心人物三阶段成长弧线
- 送礼（偏好/生日/日周限额）、正式约会（对方在剧情中实际接受才成立）、约会回忆
- 秘密与知情体系：见证者账本、公开判定、知情名单隔离
- 长期记忆：事实账本（实例 ID）、承诺回收、往事归档、按内容召回

## 手机与聊天媒体

- 短信双通道：不占回合、承诺/约定自动入账、对方按人设回复
- 聊天媒体四件套：NPC 专属图片库与视频库、共享表情包、emoji
- 模型语义选材：按对话语境选文件、附件稳定绑定不漂移
- 玩家可发表情包，对方会接梗回发

## 世界与时间

- 六国 16 城 118 地点：三级电子地图（缩放/平移/筛选/搜索）、真实旅行费用与耗时
- 分钟级时钟、时段与日/周结算、最多三年快进；现实离线冻结世界
- 世界事件日历（晚会/擂台/路演/集市等模板）＋因果导演层＋活动机遇
- 世界正典三层（本城细化/邻城一句话/传闻关键词）；可选暗线调查
- NPC 世界模拟：计划执行、独立事业与社交

## 成长·事业·经济

- 10 级成长主干、四维属性、穿搭装备加成
- 13 项技能 L1-10＋确定性检定；练习/课程/活动多渠道成长
- 三领域事业（娱乐/电竞/商业）五阶段并行、周收入结算、资产股权（公司/作品/战队/合同）
- 双币经济：华夏币（现实）/系统积分（系统玩法）不混用；账本护栏与余额事实
- 学业人生线：学分、休复学、退学、毕业与身份变迁

## 剧情与记忆

- 可选主线「星河计划」完整学期篇章＋终章伴侣选择；可暂缓/忽略
- 支线任务、长期人生目标（客观按事实核验、主观按进展）
- 都市网文文风约束（回合场景卡九项）、有限视角与人物声口
- 记忆按需注入：名册取相关 8 人、相处细节只给重点角色

## GM 后台（主持人工具）

- 角色档案编辑：性格/身份/礼物偏好/好感（写入主持人指令，旧风格作废；含主动亲近类描述时放宽铺垫节奏）
- 角色卡编辑：整卡 JSON 直编、结构校验、随档案自动同步
- 管理员发放：双币/道具/属性/进度/修为/抽奖券，绕过玩家护栏
- 商城与抽奖管理：上下架、货架轮换、品质权重
- 备份与恢复点、只读全量状态、名册总览

## 界面与尺度

- 都市系统终端风界面、四种配色主题（游戏与 GM 跨页同步）
- 手机比例聊天弹窗、电子地图、阅读专注模式、响应式窄屏
- 叙事默认成人尺度（全员成年、双方愿意为前提）

## 工程与测试

- 23 套 Python 回归＋8 套前端检查；隔离实例 HTTP 冒烟（握手验证）
- 测试与正式存档隔离（随机凭据证明同目录＋演示模式）
- 提示词按需拼装（真实存档约 11k 字符）与体积预算测试
- 存档：原子写入、版本冲突防护、事务回滚、恢复点、旧档迁移与人物归档重逢
