# NPC 图片库（手动添加）

把图片放进本文件夹即可生效，**无需重启、无需改代码**——聊天/朋友圈刷新后自动使用。

## 命名规则

```
<NPC名>.<扩展名>
```

例：

```
郭瑞莹.jpg
邓紫棋.png
走路摇.webp
杨幂.svg
```

文件名必须与 NPC 名完全一致（含标点）。支持 35 位预设 NPC 及模型自创新的任何名字。

## 支持格式与优先级

同名多格式时按此顺序取第一个存在的：

```
svg → jpg → jpeg → png → webp → gif
```

全部不存在时，自动回退到内置的程序化生成图（自带场景/人物剪影），游戏不会出现破图。

## 建议

- **竖图 3:4**（如 750×1000），聊天里显示宽 172px，清晰度足够
- 单张 ≤ 500KB；jpg/png/webp 均可
- 想换图：直接覆盖同名文件，强刷页面（Ctrl+F5）即可
- 想删图：删除文件即回退内置生成图
