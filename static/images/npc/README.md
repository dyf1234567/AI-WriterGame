# NPC 图片库

**目录结构：每个 NPC 一个文件夹，内分多个分类，每个分类放多张图。**

```
static/images/npc/
├── README.md            ← 本说明
├── 郭瑞莹/
│   ├── 自拍/            ← 分类文件夹（可自由增删改）
│   │   ├── 1.svg        ← 预置生成图（可直接覆盖/删除/追加）
│   │   ├── 2.svg
│   │   └── 3.svg
│   ├── 日常/
│   │   └── ...
│   └── 风景/
│       └── ...
├── 邓紫棋/
│   └── ...
└── ...（35 位全员）
```

## 手动添加图片

1. 找到（或新建）`NPC名/分类/` 文件夹
2. 图片放进去，**文件名任意**，支持 `jpg / jpeg / png / webp / gif / svg`
3. 刷新页面即生效——**无需重启**（游戏每次启动拉取一次图库清单 `/api/photos`）

例：

```
static/images/npc/杨幂/自拍/我的图1.jpg
static/images/npc/杨幂/约会/摩天轮.jpg     ← 新建"约会"分类也行
```

## 分类怎么被使用

NPC 发图时按附图标题关键词匹配分类：含「自拍」→ 自拍类、含「风景/天/路上」→ 风景类……
匹配不到就按「自拍 → 日常 → 风景 → 美食」优先级取第一个存在的分类，再从中随机一张
（同一人不会连续两次发同一张）。分类名完全由你定，叫「约会」「私房」「 cosplay 」都可以，
叫什么名字就靠什么关键词命中。

## 兜底规则

- 分类里一张图都没有 → 用该 NPC 其他分类
- 该 NPC 整个文件夹为空/被删 → 回退内置程序化生成图（游戏自带，永不破图）
- 预置的 `1.svg / 2.svg / 3.svg` 是程序生成的占位变体，**可以全部删掉换成你的真图**

## 建议

- 竖图 3:4（如 750×1000），单张 ≤ 500KB
- 想让某张图更容易被选中：多放几张即可（纯随机）
