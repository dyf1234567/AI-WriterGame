# NPC 视频库

聊天里 NPC 发视频用的专属素材，结构与图片库一致，即放即用、无需重启。

```
static/videos/npc/<NPC名>/<任意文件名>.mp4
```

- 每位 NPC 一个文件夹，文件夹内放任意多个 `.mp4` / `.webm` / `.mov` / `.m4v`
- NPC 发视频时从自己的文件夹随机选一条（同人避免连发同一条）
- 某位 NPC 没有文件夹或文件夹为空时，TA 发的视频消息会被聊天界面静默跳过
- 现存的 `日常随手拍.mp4` 是程序生成的 3 秒占位视频（渐变底＋名字字样），
  用真实视频替换或直接删除均可；建议竖屏或正方形、单条 15 秒内、控制在几 MB

图片库（自拍/日常/风景）在 `static/images/npc/`，规则见那边目录下的 README。
