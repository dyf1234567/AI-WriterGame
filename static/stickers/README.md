# 表情包库

聊天里所有角色共用的表情包，即放即用、无需重启。

- 文件名（去扩展名）即表情包名：`哈哈.svg` → 名字「哈哈」
- 支持 `.svg` / `.png` / `.gif` / `.jpg` / `.webp`；建议 240×240 左右的正方形
- 剧情里的角色按心情点名发（哈哈、问号、贴贴、狗头……），库里没有的名字会随机换一张顶替
- 想让某个名字必中：按上面的命名规则补一张同名文件即可

## 想换掉占位图

现在库里的 `.svg` 是程序生成的占位表情包，直接用同名 `.png`/`.jpg` 覆盖式添加
（保留或删除同名 `.svg` 均可，图库按文件逐个列出）。
